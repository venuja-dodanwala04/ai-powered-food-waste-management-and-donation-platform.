# Smart LMS: An Intelligent Learning Platform with AI Academic Assistant

## Project Overview

Smart LMS is an AI-powered Learning Management System designed to improve digital education by integrating intelligent academic assistance, personalized learning recommendations, assignment management, analytics, and collaboration tools.

## Features

- User Authentication
- Course Management
- Assignment Submission
- AI Academic Assistant
- AI Quiz Generator
- AI Study Material Summarizer
- Student Dashboard
- Lecturer Dashboard
- Attendance Management
- Notifications
- Performance Analytics
- Admin Panel
